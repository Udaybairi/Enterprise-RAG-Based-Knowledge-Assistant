# Security Guidelines

## Passwords
Passwords must be at least 14 characters long and rotated every 180 days. Multi-factor authentication is required for all production systems.

## Incident Response
Security incidents must be reported to security@acme.example within one hour. The on-call engineer triages incidents according to the severity matrix.

| Severity | Response time |
|---|---|
| SEV1 | 15 minutes |
| SEV2 | 1 hour |
